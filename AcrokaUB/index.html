САМЫЙ ВАЖНЫЙ ШАГ! Без API ключей бот не запустится.

КАК ПОЛУЧИТЬ API ID И API HASH:

  1. Перейдите на my.telegram.org
  2. Войдите через номер телефона, который будет у бота

  5. Создайте новое приложение
  6. Скопируйте api_id и api_hash

ЧАСТЫЕ ВОПРОСЫ

Где именно взять API ID и API Hash?

Шаг за шагом:

  1. Откройте my.telegram.org
  2. Введите свой номер телефона (с кодом страны, например +7)
  3. Откройте Telegram, придет код подтверждения
  4. Введите код на сайте
  5. Нажмите "API Development Tools"
  6. Нажмите "Create application"
  7. Заполните форму (любое название)
  8. Скопируйте api_id и api_hash
Что делать если не приходит код в Telegram?

Если код не приходит:

  • Убедитесь, что номер телефона введен правильно с кодом страны
  • Попробуйте войти через браузер на компьютере
  • Используйте другой номер телефона
  • Подождите 5-10 минут и попробуйте снова
Как запустить бота после установки?

После успешной установки:

$ cd AcrokaUB
$ python main.py

# Или создайте алиас для удобства:
$ echo "alias acroka='cd ~/AcrokaUB && python main.py'" >> ~/.bashrc
$ source ~/.bashrc
$ acroka
